model benchmark: a model advances only when it applies a source edit and the

## Screen policy

- One model server at a time; no concurrent large weights.
- No model deletion before its immutable hash, config, and failure reason are
  recorded here.
- A no-edit result caused by truncation remains in the keep/retest bucket.
- A verified repair advances a model to a multi-task screen; a hard loader or
  repeated no-edit/protocol failure is eligible for deletion.
